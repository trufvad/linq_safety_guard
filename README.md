# LinQ Safety Guard — Система видеоаналитики промышленной безопасности

Интеллектуальный сервис для автоматического выявления нарушений техники безопасности на производственных объектах с использованием отечественных ИИ-ускорителей LinQ TPU.

## 🎯 Решаемые задачи
- Детекция падения человека и неподвижного положения на полу
- Контроль нахождения людей в опасных зонах и вблизи работающей техники
- Выявление отсутствия средств индивидуальной защиты (СИЗ: каски, жилеты)
- Предотвращение ложных срабатываний и дедупликация событий (один инцидент — одно оповещение)
- Оперативное оповещение ответственных лиц через Web-интерфейс и Telegram-бота
- Сбор статистики и аналитики для снижения производственного травматизма и рисков по ст. 143 УК РФ

## 🏗 Архитектура решения
1. Видеопоток RTSP / серия кадров
2. Препроцессинг кадров (приведение данных к формату входного тензора)
3. Вычислительный модуль LinQ TPU (инференс нейросети через API LinQ)
4. Постпроцессинг (детекция объектов, трекинг и фильтрация ложных сработок)
5. Бэкенд-сервис (бизнес-логика зон, дедупликация инцидентов, сохранение в БД)
6. Клиентские интерфейсы: Web Dashboard для диспетчера и инженера ОТиТБ + Telegram-бот для мастера смены

## ⚡ Результаты тестирования и бенчмарки на LinQ TPU
- Модель детекции: YOLO / ResNet
- Время инференса на 1 кадр: в процессе замера на стенде
- Достигнутый FPS на LinQ TPU: в процессе замера на стенде
- Расчетная емкость: количество видеопотоков на 1 чип TPU (при частоте 5 кадр/сек на камеру)
